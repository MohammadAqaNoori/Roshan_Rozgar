# Roshan Rozgar (روشن روزگار)

A hyper-local marketplace connecting households with nearby skilled trade workers in Pakistan's informal economy.

Built for **CUI Tech Fest | AI Web Forge** — COMSATS University Islamabad.

## Problem

Pakistan's informal workforce (72.1% of non-agricultural employment) — electricians, plumbers, AC technicians, carpenters, mechanics — find work through street-corner *addas* or word of mouth. Existing job portals assume literacy, typing ability, and CVs. Households struggle to find a nearby, available, trustworthy worker.

## Solution

A web-based platform with five core outcomes:

1. **Onboarding** — Workers create profiles without conventional forms (voice/image-based registration)
2. **Discovery** — Customers find nearby, available workers
3. **Communication** — Customer-worker job negotiation without typing (voice-based)
4. **Booking** — Job confirmation with availability tracking
5. **Trust** — Post-job feedback captured for future customers
